# HPS regression transport revision 1

`c96-jt51 probe --expect-hash source-hash.txt` validates protocol0x965101 and full256-bit source signature. `c96-jt51 batch CASE.tape JOBS.tsv NEW_OUTPUT_DIRECTORY --expect-hash source-hash.txt` uploads/readbacks all four tape replicas once, configures/runs groups of up to four jobs, and writes exclusive NAME.bin files. JOBS header is exactly `name\trun_id\tidle_clocks\tevent_shift\tframes\tstride\tmode`. Name is1…79 ASCII alphanumeric/underscore/dash; run_id1…0xffffff, idle48, shift0…63, frames1…16384, stride1…0xffffff, mode0quantized or1full-resolution. No HPS communication controls logical timing after START.

GPO/GPI opcodes:0INFO,1CAPABILITIES(packed CAP_AW:AW:lanes bytes),2SELECT_LANE,3SELECT_MASK,4TAPE_ADDR,5TAPE_LOW24,6TAPE_MID24,7TAPE_HIGH16(commit+increment),8TAPE_READ_LOW24(latch),9TAPE_READ_MID24,10TAPE_READ_HIGH16(increment),11COMMIT,12START_MASK,13STATUS,14COUNT,15ABORT_MASK,16CFG_INDEX,17CFG_WRITE24,18CFG_READ(index arg),19SAMPLE_ADDR,20SAMPLE_LOW24(latch),21SAMPLE_HIGH16(increment),22META(index arg),23SOURCE_WORD(index0…15, least-significant16-bit word first).

CFG fields0length,1event_first,2idle_low24,3idle_high24,4event_shift,5capture_limit,6output_mode,7run_id,8stride. STATUS bits0ready,1busy,2done,3failed; bits15:8 lane error. META fields0executed,1error,2/3logical_clock low/high24,4/5first_clock,6/7last_clock,8/9failure_clock,10last_status,11/12clock_Hz low/high24,13capture_capacity,14tape_capacity,15mode,16active_run_id,17generation. Mutations require all lanes idle except ABORT; lane selection and read-only queries are allowed while running. COMMIT requires validated config; START clears readiness. Actual run ID is latched independently of future config.

## Result binary

All integers little endian.160-byte header, then count×5 bytes; magic8=`JT51FP01`. u32 fields at offsets8header_bytes=160,12version=1,16protocol,20physical_clock_Hz,24active_run_id,28lane,32count,36requested_frames,40stride,44mode,48terminal_STATUS,52error_code,56executed_tape_records,60tape_length. u64 fields64first_clock,72last_clock,80logical_clock,88failure_clock. u32 fields96generation,100event_shift. u64 at104idle_clocks. Bytes112…143 are the canonical big-endian32-byte SHA256 source signature (same hex as source-hash.txt). u32 at144event_first,148sample_bytes=5; bytes152…159 reserved0.

Each five-byte little-endian word is {status8,left16,right16}: right occupies bits15:0, left31:16, status39:32. Signed PCM is16-bit two's complement. Mode1 uses xleft/xright in the same positions and must be labelled accordingly. Native sample clocks are first_clock+i×64×stride; driver and decoder require last_clock consistency. Every run must be terminal done, nonfailed, count=requested, executed=length, error0 before qualification. Failures remain files/metadata and never qualify.

The decoder emits quantized CSV `sample,left,right,clock,status`, or full-resolution `sample,xleft,xright,clock,status`; it never invents uncaptured columns. New files only. Source/tape/job/tool/binary SHA256 and board boot identity are bound by the outer controller. Reference comparison remains the existing unmodified finite observer on the recorded public PCM; model execution is on FPGA.
